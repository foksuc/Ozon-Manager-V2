# Проверка исходного выпуска — 16.10.2026

Это локальный Windows-инструмент для одного пользователя. Пакет подготовлен для загрузки исходников на GitHub; публикация и отправка изменений в Ozon в рамках аудита не выполнялись.

## Что проверено

- Backend: подтверждение неизменяемого плана, Fresh Check, привязка аккаунта, блокировка повторных отправок UNKNOWN, readback, DPAPI-история и обработка отказов Ozon.
- Безопасность: loopback, TrustedHost/Origin, фиксированные внешние API-хосты, запрет redirects/proxy environment, исключение ключей из публичных ответов и истории, ограниченная выдача статики.
- Запуск: START/STOP уже используют локальные runtime с проверкой SHA256; developer runner исправлен для переноса в другую папку. Папки данных и зависимостей отделены от исходников.
- Найденный конкурентный дефект сверки стратегий исправлен: общая блокировка аккаунта удерживается и освобождается даже при ошибке.
- Истёкшая одноразовая диагностика конкретного товара удалена. Исторические отчёты, рабочие снимки, базы, кеши, зависимости, история, `.env` и Git metadata исключены из чистого ZIP.
- npm audit: **0 известных уязвимостей**, 200 зависимостей в отчёте. OSV для **23 Python-пакетов: 0 совпадений**. Это состояние advisory-сервисов на дату проверки, не гарантия отсутствия неизвестных уязвимостей.

## Ограничения

- LIVE-черновики не реализованы; зашифрованная история операций не заменяет их. Полная первоначальная приёмка R1/A5 не объявляется завершённой.
- История ограничена 16 МБ на раздел; встроенного архивирования пока нет. При достижении лимита новые отправки блокируются. Не удаляйте историю с неопределёнными результатами.
- Полный новый LIVE-прогон всех видов записи и отката не проводился. Пользователь сообщил о корректной работе остальных mutations; это отдельно от автоматических и синтетических тестов.
- Дополнительная проверка A3/R1-07 снята пользователем; новая LIVE-приёмка Performance исключена из объёма. Это не результат PASS этих проверок.
- Шифрование DPAPI привязано к пользователю Windows: перенос рабочей папки не является переносом подключений на другой компьютер.
- Проверка секретов основана на закрытом составе ZIP, сигнатурах и отдельной проверке содержимого. Не используйте рабочую папку вместо исходного архива при публикации.
